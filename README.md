# Telegram PC Control v2

Отправь боту картинку как фото, затем `/showimage` — она откроется на весь экран Windows-компьютера.
Нажми Esc или клик мышью, чтобы закрыть.

Также доступны `/screenshot`, `/status`, `/open`, `/lock`, `/shutdown`, `/restart`.

`/mouse` — открывает панель с кнопками-стрелками для перемещения курсора, клик/двойной клик/ПКМ, скролл
и кнопкой смены шага перемещения (10 / 20 / 50 / 100 px).

`/music` (или `/spotify`) — панель управления плеером: play/pause, следующий/предыдущий трек, громкость,
открыть приложение Spotify. Работает через системные медиа-клавиши Windows, поэтому управляет тем плеером,
который сейчас активен (Spotify, если он открыт и играет), — отдельный API-ключ Spotify не нужен.

`/keyboard` — панель с клавишами (Enter, Esc, Tab, Backspace, стрелки, Win, Alt+Tab, Ctrl+C/V/Z).
`/type <текст>` — печатает произвольный текст (в том числе кириллицу) в окно, активное сейчас на ПК.
`/key <имя>` — нажать одну клавишу командой, например `/key enter`.

`/antiafk on|off` — анти-АФК: раз в ~50 секунд едва заметно шевелит курсор мыши, чтобы Windows,
Slack/Teams/Discord и подобные программы не показывали статус "нет на месте" и экран не гас по таймеру.

`/antiafkgame on|off` — отдельный анти-АФК для игр: раз в минуту нажимает Пробел и делает клик мышью
(в текущей позиции курсора) — многие игры не засчитывают лёгкое покачивание мыши за активность,
а вот нажатие клавиши и клик обычно засчитывают. Работает независимо от обычного `/antiafk`.

## 🎮 WASD-панель для игр

`/wasd` — открывает панель с W/A/S/D, Space, Shift, Ctrl, Q/E/R — раскладка под типичное
управление в играх. Два режима (переключаются кнопкой на панели):
- **Тап** — каждое нажатие кнопки просто быстро "кликает" клавишу (как обычная клавиатура-панель).
- **Удержание** — нажатие на W/A/S/D зажимает клавишу (для непрерывного движения/бега), повторное
  нажатие той же клавиши отпускает её. На случай, если забудешь отпустить — сработает автоотпускание
  через 60 секунд, чтобы клавиша не осталась "залипшей" в игре.

## 🗂 Запуск любых программ по названию

`/open [название или путь]` — теперь необязательно указывать точный путь к .exe. Можно просто
написать название программы, например `/open telegram` или `/open steam` — бот поищет подходящий
ярлык в меню «Пуск» и на рабочем столе и запустит его. Полный путь в кавычках (как раньше) тоже
работает, если нужна точность.

`/apps [название]` — если найдётся несколько похожих программ, покажет их списком с кнопками —
нажимаешь на нужную, и она запускается.

## 🖱 Курсор мыши на скриншотах и трансляции

Windows не даёт штатно "сфотографировать" системный курсор мыши вместе с экраном, поэтому на
`/screenshot` и в `/live` бот сам рисует поверх кадра жёлтую стрелку в текущей позиции курсора —
так на скриншоте/трансляции всегда видно, где сейчас мышь.

## ⌨️ Меню команд в Telegram

При запуске бот сам регистрирует список команд в Telegram (кнопка "/" в поле ввода) — там сразу
видно все доступные команды с короткими описаниями, без необходимости помнить их наизусть.
`/start` тоже показывает полный список, но уже разбитый по разделам (Система, Мышь/клавиатура,
Медиа, Anti-AFK, Прочее).

## 🔴 Прямая трансляция экрана

`/live [сек]` — запускает "прямую трансляцию": бот раз в ~2.5 секунды (можно указать своё значение,
минимум 1.5 сек, например `/live 2`) присылает новый кадр экрана в то же самое сообщение, а под кадром
сразу доступны кнопки управления мышью — получается "смотрю и управляю" почти как в AnyDesk/TeamViewer,
прямо в чате Telegram.

`/stoplive` — остановить трансляцию.

**Важно понимать ограничение платформы:** Telegram Bot API не поддерживает настоящую видео-трансляцию
(WebRTC/RTMP и т.п.) — только обмен сообщениями и файлами. Поэтому "трансляция" технически — это быстро
обновляющиеся кадры (скриншоты), а не непрерывное видео. Слишком маленький интервал (меньше ~1.5 сек)
Telegram может начать ограничивать (flood control), поэтому оптимально 2–3 секунды между кадрами.

Другие полезные команды: `/volume up|down|mute` — громкость системы; `/clipboard` — показать текст
из буфера обмена ПК; `/setclip <текст>` — записать текст в буфер обмена ПК (потом Ctrl+V где угодно);
`/battery` — заряд батареи ноутбука; `/ip` — локальный и публичный IP-адрес ПК; `/app` — открыть
Telegram Mini App (визуальная панель, см. раздел ниже).

🔐 Пароль-сессия: при каждом запуске бота, а затем каждые 24 часа, бот считает сессию истёкшей
и требует прислать пароль обычным текстовым сообщением (значение — переменная `APP_PASSWORD` в `.env`,
по умолчанию `fura`). Пока пароль не введён верно, команды не выполняются — придёт напоминание
"🔐 Сессия истекла...". После верного пароля доступ открыт на 24 часа.

## 🖥 Панель управления (GUI)

Есть графическая панель `control_panel.pyw` — современный тёмный интерфейс со скруглёнными карточками,
плавным появлением окна, анимированным индикатором статуса и анимированным переключателем автозапуска.
В ней можно:
- красиво поменять **Bot Token**, **Telegram User ID**, **пароль (APP_PASSWORD)** и **Mini App URL**
  (поля скрыты, есть кнопка 👁 показать/скрыть, вставка работает даже с русской раскладкой);
- одной кнопкой **запустить/остановить бота в фоне** — без окна консоли;
- включить **автозапуск бота вместе с Windows** анимированным тумблером;
- свернуть панель в **системный трей** (значок внизу справа, своя иконка приложения) — оттуда тоже
  можно открыть панель, запустить/остановить бота и выйти.

### Установка и первый запуск
1. Создай бота через @BotFather (получишь Bot Token).
2. Запусти `install.bat` (двойной клик).
   - Python ставить заранее **не обязательно** — если его нет, `install.bat` сам скачает и тихо установит
     Python с официального python.org (либо через `winget`, если он есть в системе), спросит разрешение
     администратора при необходимости, и продолжит установку зависимостей автоматически.
   - Если что-то пошло не так — весь процесс подробно пишется в файл **`install.log`** рядом со скриптом,
     присылай его текст, если установка не проходит.
   - Частая причина ложного "Python не найден"/зависаний на Windows 10/11 — фейковая заглушка
     `python.exe`, которую подсовывает Microsoft Store, если реальный Python не установлен
     (открывает магазин вместо интерпретатора). `install.bat` теперь проверяет это и не даёт себя обмануть.
3. Открой панель управления — дважды кликни **`ControlPanel.vbs`** (не мелькает окно консоли).
4. В панели заполни Bot Token, User ID, пароль → «💾 Сохранить настройки».
5. Нажми «▶ Запустить бота» — бот запустится в фоне. Панель можно закрыть (свернётся в трей),
   бот продолжит работать.
6. Напиши боту в Telegram `/start` и пришли пароль, чтобы открыть сессию.
7. При желании включи переключатель «Запускать при старте Windows».

### Установка вручную (если авто-установка не подошла)
1. Установи Python 3.11+ с https://www.python.org/downloads/ , отметь галочку **"Add python.exe to PATH"**.
2. Запусти `install.bat` ещё раз — Python уже будет найден, установятся только зависимости.

### Запуск без панели (классический консольный режим, для отладки)
Заполни `.env` вручную и запусти `run.bat` — увидишь окно с логами.

Логи фонового бота (запущенного через панель) пишутся в файл `bot.log` рядом с `bot.py`.

## 📱 Mini App

В комплекте есть `mini_app/index.html` — красивая мобильная веб-панель (тёмная тема, тот же стиль,
что и десктопное приложение) с кнопками: напечатать текст, быстрые клавиши, управление плеером,
переключатель Anti-AFK, копирование текста в буфер обмена ПК.

**Как подключить (один раз, бесплатно):**
1. Создай публичный репозиторий на GitHub (или используй уже существующий).
2. Загрузи туда файл `mini_app/index.html`.
3. В настройках репозитория открой `Settings → Pages`, включи GitHub Pages для ветки `main`.
4. Через минуту GitHub выдаст ссылку вида `https://твой-логин.github.io/репозиторий/index.html` — это и есть HTTPS-ссылка (Telegram требует именно HTTPS).
5. Вставь эту ссылку в панели управления в поле **MINI APP URL** → «Сохранить настройки»
   (или пропиши `MINI_APP_URL=...` прямо в `.env`).
6. В Telegram напиши боту `/app` — придёт кнопка «🚀 Открыть Mini App».

**Важная особенность платформы:** Telegram закрывает Mini App сразу после каждого отправленного
действия (`sendData`) — так работает API Telegram, это не баг. Поэтому для одиночных команд
(напечатать текст, поставить на паузу, скопировать в буфер) Mini App отлично подходит, а для
быстрых повторных нажатий (подвигать мышкой, понажимать стрелки много раз подряд) удобнее
использовать `/mouse`, `/keyboard`, `/music` прямо в чате с ботом — там кнопки не закрываются
после каждого нажатия.

Важно: никому не передавай BOT_TOKEN, .env и пароль APP_PASSWORD.

## 🗑 Полное удаление

Если хочешь снести программу целиком — запусти **`Uninstall.bat`** (двойной клик) и подтверди, введя `YES`.
Он сам:
- остановит бота и панель управления,
- уберёт автозапуск с Windows,
- удалит виртуальное окружение `.venv`,
- удалит `.env` (с токеном и паролем) и все служебные файлы,
- удалит всю папку программы целиком, включая сам `Uninstall.bat`.

После этого стоит на всякий случай отозвать токен бота через @BotFather → `/revoke` — сам файл
удаления Telegram-токен не трогает, он только чистит файлы на компьютере.
